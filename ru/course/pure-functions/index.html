05 Чистые функции

Цель урока Научиться отличать чистые функции от нечистых и переписывать нечистые так, чтобы они не мутировали внешние данные, а возвращали новое значение.

Чистые функции крайне важны. При этом чистая функция не обязательно идемпотентна: x => x + 1 чистая, но, применив ее к собственному результату, мы получим новое значение. Если вам нужны сайд эффекты, то группируйте их в отдельные функции и отделяйте от чистых функций. Любая программа, особенно в вебе, нуждается в сайд эффектах (изменение DOM дерева (tree), запросы к серверу (fetch), чтение из файла (readFile) и т. п.)

// НЕчистая функция
// ===============================
let user = { name: 'John', age: 25 }

const changeAge = () => user.age = 30

// мы мутируем внешнюю переменную и создаем сайд эффекты
// программа будет вести себя непредсказуемо, так как с этой
// переменной могут работать несколько функций, и отловить ошибку будет сложнее
changeAge()
console.log(user) // { name: 'John', age: 30 }
// ===============================
// Такой код допустим, если мы создаем независимые модули с собственным замыканием
// ===============================
// useChangeUser :: Object -> Object
const useChangeUser = (user) => {

  let userBase = structuredClone(user) // обязательно клонируем

  const changeAge = (newAge) => userBase.age = newAge

  // для работы снаружи с данными
  return {
    userBase,
    changeAge
  }
}

// Но даже в этом случае лучше делать так
// useImmutableUser :: Object -> Object
const useImmutableUser = (user) => {

  let userBase = structuredClone(user) // обязательно клонируем

  const changeAge = (newAge) => userBase = ({
    ...userBase, // или structuredClone(userBase) или JSON.parse(JSON.stringify(userBase))
    age: newAge
  })

  // для работы снаружи с данными
  // getUser каждый раз отдает актуальный объект: changeAge заменяет его новым
  return {
    getUser: () => userBase,
    changeAge
  }
}

const john = useImmutableUser({ name: 'John', age: 25 })
const before = john.getUser()
john.changeAge(30)
console.log(john.getUser()) // { name: 'John', age: 30 } изменение видно снаружи
console.log(before) // { name: 'John', age: 25 } прежний объект не изменился
// ===============================
// А теперь давайте поправим пример выше
// ===============================
let user = { name: 'John', age: 25 }

// Чистая функция
// changeAge :: (Number, Object) -> Object
const changeAge = (newAge, user) => ({
  ...user,
  age: newAge
})

//  улучшим
// или если требуется глубокое клонирование и каррирование

// changeAgeCurried :: Number -> Object -> Object
const changeAgeCurried = (newAge) => (user) => ({
  ...structuredClone(user), // или JSON.parse(JSON.stringify(user))
  age: newAge
})

// тут мы проверим все
const changedUser = changeAgeCurried (30) (user)

console.log(user) // { name: 'John', age: 25 } сохранил первоначальное состояние
console.log(changedUser) // { name: 'John', age: 30 } получили нового пользователя без побочных эффектов
// ===============================

Главное

  • Чистая функция не обязательно идемпотентна: x => x + 1 чистая, но, применив ее к собственному результату, мы получим новое значение.
  • Любая программа, особенно в вебе, нуждается в сайд эффектах: изменение DOM, запросы к серверу, чтение из файла. Группируйте их в отдельные функции и отделяйте от чистых.
  • Функция, которая мутирует внешнюю переменную, создает сайд эффекты: с этой переменной могут работать несколько функций, и отловить ошибку будет сложнее.
  • Чистая функция не меняет переданный объект, а возвращает новый: через spread, а если требуется глубокое клонирование, — через structuredClone.
  • Даже в модуле с собственным замыканием состояние лучше заменять новым объектом, чем мутировать.

Упражнения

Упражнение 1

Функция addTagImpure меняет пост, который ей передали. Напишите чистую addTag: она возвращает новый пост с добавленным тегом и не трогает исходный. Учтите, что tags — вложенный массив: если скопировать только сам объект, массив останется общим.

Заготовка

// addTagImpure :: (String, Object) -> Object
// НЕчистая: меняет пост, который ей передали
const addTagImpure = (tag, post) => {
  post.tags.push(tag)
  return post
}

// addTag :: (String, Object) -> Object
// ваш код

const post = { title: 'FP', tags: ['js'] }
const taggedPost = addTag('fp', post)

console.log(post.tags) // исходный пост не изменился
console.log(taggedPost.tags)

Ожидаемый вывод

[
  "js"
]
[
  "js",
  "fp"
]
Показать решение
// addTagImpure :: (String, Object) -> Object
// НЕчистая: меняет пост, который ей передали
const addTagImpure = (tag, post) => {
  post.tags.push(tag)
  return post
}

// addTag :: (String, Object) -> Object
// Чистая: новый объект и новый массив tags, исходный пост не меняется
const addTag = (tag, post) => ({
  ...post,
  tags: [...post.tags, tag],
})

const post = { title: 'FP', tags: ['js'] }
const taggedPost = addTag('fp', post)

console.log(post.tags) // исходный пост не изменился
console.log(taggedPost.tags)

Упражнение 2

Результат finalPriceImpure зависит от внешней переменной discount: с тем же аргументом функция возвращает другую цену, если discount изменили. Напишите чистую finalPrice, которая получает процент скидки аргументом. Запустите код и сравните строки до и после изменения discount.

Заготовка

let discount = 10

// finalPriceImpure :: Number -> Number
// НЕчистая: результат зависит от внешней переменной discount
const finalPriceImpure = (price) => price - price * discount / 100

// finalPrice :: (Number, Number) -> Number
// ваш код

console.log(`нечистая: ${finalPriceImpure(200)}, чистая: ${finalPrice(10, 200)}`)

discount = 50 // кто-то изменил внешнюю переменную

console.log(`нечистая: ${finalPriceImpure(200)}, чистая: ${finalPrice(10, 200)}`)

Ожидаемый вывод

нечистая: 180, чистая: 180
нечистая: 100, чистая: 180
Показать решение
let discount = 10

// finalPriceImpure :: Number -> Number
// НЕчистая: результат зависит от внешней переменной discount
const finalPriceImpure = (price) => price - price * discount / 100

// finalPrice :: (Number, Number) -> Number
// Чистая: все, от чего зависит результат, приходит аргументами
const finalPrice = (percent, price) => price - price * percent / 100

console.log(`нечистая: ${finalPriceImpure(200)}, чистая: ${finalPrice(10, 200)}`)

discount = 50 // кто-то изменил внешнюю переменную

console.log(`нечистая: ${finalPriceImpure(200)}, чистая: ${finalPrice(10, 200)}`)
