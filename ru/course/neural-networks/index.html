24 Нейронные сети и теория категорий

Цель урока Понять, как нейросеть прямого распространения складывается из функций — нейрон, слой и сеть как композиция слоёв, — и какую часть этой картины описывает теория категорий.

Давайте с вами посмотрим на нейронные сети глазами функционального программиста — как на композицию функций — и свяжем это с теорией категорий. Для этого вначале повторим, что такое категория: мы говорили о ней в предыдущих главах.

Категория — это объекты, морфизмы (стрелки между объектами) и композиция морфизмов, для которой выполняются два закона: тождество (у каждого объекта есть тождественный морфизм, и композиция с ним ничего не меняет) и ассоциативность (неважно, как расставить скобки в цепочке композиций). В программировании в роли объектов обычно выступают типы, а в роли морфизмов — функции между ними.

Теперь о том, как устроена нейросеть. Искусственный нейрон умножает каждый вход на свой вес, складывает результаты, прибавляет смещение (bias) и пропускает получившееся число через нелинейную функцию активации, например ReLU: max(0, z).

Слой — это несколько нейронов, которые получают одни и те же входы. Слой целиком — функция: на входе вектор чисел, на выходе вектор чисел, по одному от каждого нейрона. В сети прямого распространения (feedforward) — базовой архитектуре — слои идут цепочкой: выход одного слоя становится входом следующего. Значит, сеть — это композиция функций-слоёв: f(x) = f3(f2(f1(x))).

Нелинейность в скрытых слоях обязательна. Без функции активации каждый слой — линейная функция (точнее, аффинная: умножение на веса плюс смещение), а композиция аффинных функций снова аффинна. Сколько таких слоёв ни ставь, сеть сведётся к одному слою и не сможет, например, решить задачу XOR из примера ниже. Выходной слой при этом может быть и линейным, как в том же примере.

Архитектуру — сколько слоёв, сколько в них нейронов, какие функции активации — выбирает создатель сети. А веса и смещения — обучаемые параметры: их не передают при вызове, их подбирает алгоритм обучения, после чего они фиксируются. Вычисление обученной сети с зафиксированными параметрами — чистая функция от входа: одинаковые входы дают одинаковый выход.

Коротко об обучении. В самом частом случае (обучение с учителем) есть примеры с правильными ответами. Функция потерь (loss) выдаёт число: насколько ответы сети отличаются от правильных. Градиентный спуск много раз понемногу сдвигает каждый параметр в ту сторону, в которой потери уменьшаются. Куда и насколько сдвигать каждый параметр, показывает градиент функции потерь, а вычисляет его сразу для всех параметров обратное распространение ошибки (backpropagation): правило дифференцирования сложной функции, применённое к композиции слоёв от выхода к входу.

Теперь то же на языке категорий. Объекты — пространства векторов нужной длины (в примере ниже: 2 числа на входе, 2 в скрытом слое, 1 на выходе), морфизмы — функции между такими пространствами; каждый слой — морфизм, и сеть целиком, композиция слоёв, — тоже морфизм. По закону ассоциативности неважно, как группировать слои: pipe(pipe(a, b), c) и pipe(a, pipe(b, c)) — одна и та же функция. Тождественный морфизм — функция, которая возвращает вход без изменений: если добавить её в цепочку, сеть не изменится.

Важно не переоценивать эту связь: теория категорий здесь описывает, как слои стыкуются между собой, но не объясняет, почему сеть учится. Описать на этом языке и обучение тоже пытаются, но это уже исследовательская тема (например, статья «Backprop as Functor», Fong, Spivak, Tuyéras, 2019), и в курсе мы её не трогаем.

Соберём всё вместе. Ниже — схема небольшой сети и та же сеть в коде: нейрон и слой — функции, а сеть — их композиция через pipe.

// ==== Схема сети из примера ниже ====

           вход x: 2 числа
                 |
                 v
+-------------------------------------+
| скрытый слой: 2 нейрона             |
| нейрон = relu(сумма(вес * вход)     |
|               + смещение)           |
+-------------------------------------+
                 |  2 числа
                 v
+-------------------------------------+
| выходной слой: 1 нейрон             |
| нейрон = сумма(вес * вход)          |
|          + смещение                 |
+-------------------------------------+
                 |
                 v
           выход y: 1 число

веса и смещения — обучаемые параметры
сеть — композиция слоёв: y = output(hidden(x))
// ==== Та же сеть в коде ====
// параметры уже подобраны: это решение задачи XOR из учебника
// Goodfellow, Bengio, Courville «Deep Learning», раздел 6.1
// там их задали вручную, в реальной сети их находит обучение

// pipe :: ((a -> b), (b -> c), ..., (y -> z)) -> a -> z
const pipe = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x)

// функции активации
// relu :: Number -> Number
const relu = (z) => Math.max(0, z)
// identity :: a -> a
const identity = (z) => z

// взвешенная сумма: каждый вход умножаем на свой вес и складываем
// weightedSum :: ([Number], [Number]) -> Number
const weightedSum = (weights, inputs) =>
  inputs.reduce((sum, x, i) => sum + x * weights[i], 0)

// нейрон: взвешенная сумма входов плюс смещение,
// результат проходит через функцию активации
// веса, смещение и активация задаются при создании нейрона,
// при вызове он получает только входы
// neuron :: ([Number], Number, (Number -> Number)) -> [Number] -> Number
const neuron = (weights, bias, activation) => (inputs) =>
  activation(weightedSum(weights, inputs) + bias)

// слой: несколько нейронов получают одни и те же входы,
// на выходе по числу от каждого нейрона
// layer :: [[Number] -> Number] -> [Number] -> [Number]
const layer = (neurons) => (inputs) => neurons.map((n) => n(inputs))

// скрытый слой: 2 числа -> 2 числа, активация relu
// hidden :: [Number] -> [Number]
const hidden = layer([
  neuron([1, 1], 0, relu),
  neuron([1, 1], -1, relu),
])

// выходной слой: 2 числа -> 1 число, без нелинейности, как в учебнике
// output :: [Number] -> [Number]
const output = layer([
  neuron([1, -2], 0, identity),
])

// сеть — композиция слоёв
// network :: [Number] -> [Number]
const network = pipe(hidden, output)

// ответ сети одним числом
// getAnswer :: [Number] -> Number
const getAnswer = pipe(network, ([y]) => y)

for (const x of [[0, 0], [0, 1], [1, 0], [1, 1]]) {
  console.log(`${x[0]} XOR ${x[1]} = ${getAnswer(x)}`)
}
// 0 XOR 0 = 0
// 0 XOR 1 = 1
// 1 XOR 0 = 1
// 1 XOR 1 = 0

Главное

  • Нейрон умножает каждый вход на свой вес, складывает результаты, прибавляет смещение и пропускает число через нелинейную функцию активации, например ReLU: max(0, z).
  • Слой — функция из вектора чисел в вектор чисел, а сеть прямого распространения — композиция функций-слоёв: f(x) = f3(f2(f1(x))).
  • Без нелинейности в скрытых слоях композиция аффинных слоёв снова аффинна: сеть сводится к одному слою и не может, например, решить задачу XOR.
  • Веса и смещения подбирает алгоритм обучения, после чего они фиксируются; обученная сеть с зафиксированными параметрами — чистая функция от входа.
  • Теория категорий описывает, как слои стыкуются между собой, но не объясняет, почему сеть учится.

Упражнения

Упражнение 1

Возьмите скрытый слой hidden из урока и не меняйте его. Подберите веса и смещение выходного нейрона (активация identity) так, чтобы сеть вычисляла OR, а затем AND, и выведите таблицы истинности. Подсказка: сначала посчитайте, что hidden выдаёт на входах [0, 0], [0, 1], [1, 0] и [1, 1].

Заготовка

// pipe :: ((a -> b), (b -> c), ..., (y -> z)) -> a -> z
const pipe = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x)

// relu :: Number -> Number, то же, что max(0, z)
const relu = (z) => (z > 0 ? z : 0)
// identity :: a -> a
const identity = (z) => z

// weightedSum :: ([Number], [Number]) -> Number
const weightedSum = (weights, inputs) =>
  inputs.reduce((sum, x, i) => sum + x * weights[i], 0)

// neuron :: ([Number], Number, (Number -> Number)) -> [Number] -> Number
const neuron = (weights, bias, activation) => (inputs) =>
  activation(weightedSum(weights, inputs) + bias)

// layer :: [[Number] -> Number] -> [Number] -> [Number]
const layer = (neurons) => (inputs) => neurons.map((n) => n(inputs))

// скрытый слой из урока
// hidden :: [Number] -> [Number]
const hidden = layer([
  neuron([1, 1], 0, relu),
  neuron([1, 1], -1, relu),
])

// сеть: скрытый слой, затем один выходной нейрон
// gate :: ([Number], Number) -> [Number] -> Number
const gate = (weights, bias) =>
  pipe(hidden, layer([neuron(weights, bias, identity)]), ([y]) => y)

// ваш код: подберите веса и смещение
const or = gate([0, 0], 0)
const and = gate([0, 0], 0)

const inputs = [[0, 0], [0, 1], [1, 0], [1, 1]]
for (const [name, net] of [['OR', or], ['AND', and]]) {
  for (const x of inputs) {
    console.log(`${x[0]} ${name} ${x[1]} = ${net(x)}`)
  }
}

// pipe :: ((a -> b), (b -> c), ..., (y -> z)) -> a -> z
const pipe = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x)

// relu :: Number -> Number, то же, что max(0, z)
const relu = (z) => (z > 0 ? z : 0)
// identity :: a -> a
const identity = (z) => z

// weightedSum :: ([Number], [Number]) -> Number
const weightedSum = (weights, inputs) =>
  inputs.reduce((sum, x, i) => sum + x * weights[i], 0)

// neuron :: ([Number], Number, (Number -> Number)) -> [Number] -> Number
const neuron = (weights, bias, activation) => (inputs) =>
  activation(weightedSum(weights, inputs) + bias)

// layer :: [[Number] -> Number] -> [Number] -> [Number]
const layer = (neurons) => (inputs) => neurons.map((n) => n(inputs))

// два слоя; активацию скрытого слоя передаём параметром
// deepWith :: (Number -> Number) -> [Number] -> Number
const deepWith = (activation) => pipe(
  layer([
    neuron([1, 2], 1, activation),
    neuron([3, -1], 0, activation),
  ]),
  layer([neuron([2, 1], -4, identity)]),
  ([y]) => y,
)

// deep :: [Number] -> Number
const deep = deepWith(identity)

// подставляем скрытый слой в выходной нейрон:
// 2 * (x1 + 2 * x2 + 1) + (3 * x1 - x2) - 4 = 5 * x1 + 3 * x2 - 2
// single :: [Number] -> Number
const single = pipe(layer([neuron([5, 3], -2, identity)]), ([y]) => y)

for (const x of [[0, 0], [1, 0], [0, 1], [2, 3]]) {
  console.log(`[${x}]: deep = ${deep(x)}, single = ${single(x)}`)
}

// с relu второй скрытый нейрон на входе [0, 1] выдаёт не -1, а 0,
// и ответы расходятся: формула одного нейрона больше не подходит
console.log(`с relu, [0,1]: deep = ${deepWith(relu)([0, 1])}, single = ${single([0, 1])}`)
